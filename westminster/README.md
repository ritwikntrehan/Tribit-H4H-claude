# Westminster application reference folder

**Working scenario:** hypothetical four-unit residential project in Westminster, California. **Status:** official-source research, not a completed filing package. Checked 2026-11-07.

The city states that new residential projects with four or more new units require **Development Review** before Building Division construction plan check. This folder targets that planning-stage process, not the subsequent building permit.

## Official city documents

The official PDF files are **linked, not mirrored** here. The GitHub integration currently supports text files but not binary PDF uploads. Download the originals from the city before preparing an actual application.

| Document | Source | Use |
|---|---|---|
| **Development Review Application Packet (PL-101)** | [Official PDF](https://www.westminster-ca.gov/home/showpublisheddocument/536/637544150393130000) | Main application, submittal checklist, residential questionnaire, hazardous waste statement, plan specifications, water quality affidavit, notification instructions, replacement housing form |
| **Planning applications, forms and fees** | [City index](https://www.westminster-ca.gov/departments/community-development/planning-division/applications-forms-and-permits) | Current versions of Development Review, General Land Use and Development, Density Bonus, Deposit Account, SB 330 replacement housing forms, fee schedule |
| **City development review process** | [City process](https://www.westminster-ca.gov/departments/community-development/planning-division/development-review-process) | Steps from pre-submittal through occupancy |
| **Building permit application and declarations** | [Building forms](https://www.westminster-ca.gov/departments/community-development/building-division/application-forms) | Later building-permit stage |
| **Building plan-check requirements** | [Plan-check guidance](https://www.westminster-ca.gov/departments/community-development/building-division/building-permits-plan-checks) | Architectural, structural and energy documentation for later stage |
| **Development engineering forms** | [Engineering forms](https://www.westminster-ca.gov/departments/public-works/engineering-division/development-engineering) | Grading, subdivision and right-of-way work, as applicable |
| **Current design guidelines** | [Design guidelines](https://www.westminster-ca.gov/departments/community-development/planning-division/zoning-code/design-guidelines-manual) | Residential design requirements |
| **Planning Division** | [City contact page](https://www.westminster-ca.gov/departments/community-development/planning-division) | Verify entitlement pathway, completeness checklist, fees, current submission format |

**Important:** The PL-101 PDF appears to be an older publication and includes fee amounts and physical-media/printed-set instructions that may be stale. The city now advertises Westminster Build online permitting. Confirm whether planning-stage Development Review can be submitted through that portal and the current submission specifications before filing. Do not treat fees in the old packet as current.
